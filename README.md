# COMP 301 / COMP 401: Introduction to Computer Security

This repository contains the course materials for COMP 301 and COMP 401, including lecture notes and lab activities for the semester.

## Course Information

This course introduces students to the principles and practices of computer security, covering cryptography, threats, secure coding, exploitation, network security, digital forensics, and security policy.

## Repository Structure

- notes/ — weekly lecture notes and course topic summaries
- labs/ — hands-on lab assignments and exercises

## Course Description

The course meets in person and provides an introductory survey of computer security topics, including basic security goals, encryption, penetration testing, software exploitation, reverse engineering, packet sniffing, and secure coding. Students learn both the theory and practical tools used in cybersecurity.

## Course Learning Outcomes

### COMP 301

- Understand the principles of computer security and its importance in today’s digital world
- Identify common security threats, vulnerabilities, and attack vectors
- Understand cryptography and its role in securing data
- Understand identity and access management (IAM) principles and technologies
- Understand secure network design and best practices
- Understand wireless, mobile, and IoT security challenges
- Understand common application attacks and secure application development practices
- Understand endpoint security, cloud security, and resilience strategies
- Understand standards, policies, risk management, and privacy principles
- Develop practical skills using security tools and technologies

### COMP 401

- All of the above outcomes, plus:
- Analyze security scenarios and implement proper security measures
- Communicate effectively about security concepts, threats, and solutions
- Demonstrate ethical behavior and professional responsibility in the field

## Course Design Overview

### Week 1: Introduction to Security
- Security principles, vulnerabilities, threat actors, attack vectors, social engineering, malware, and security control types

### Week 2: Cryptography
- Cryptographic principles, historical cryptosystems, symmetric/asymmetric encryption, hash functions, MACs, signatures, and digital certificates

### Week 3: Identity and Access Management
- Authentication, IAM protocols, accounts, access control models, and filesystem permissions

### Week 4: Network Attacks and Secure Network Protocols
- DDoS, DNS issues, ARP poisoning, MITM, HTTPS, SSH, and IPSec

### Week 5: Secure Network Design
- Segmentation, firewalls, IDS/IPS, VPNs, port security, and load balancing

### Week 6: Wireless, Mobile, and IoT Security
- WLAN standards, Bluetooth security, embedded systems, and mobile device security

### Week 7: Application Attacks
- XSS, CSRF, SSRF, memory vulnerabilities, injection attacks, race conditions, and privilege escalation

### Week 8: Secure Application Development
- Secure coding, version control, code review, fuzzing, OWASP, and input validation

### Week 9: Endpoint Security
- Endpoint protection, DLP, hardening, patch management, and boot integrity

### Week 10: Cloud Security
- Cloud deployment models, containers, virtualization, SDN, storage, and cloud controls

### Week 11: Cybersecurity Resilience and Security Assessment
- Data protection, redundancy, vulnerability scans, event management, and penetration testing

### Week 12: Digital Forensics and Incident Response
- IR development, containment, digital evidence, and forensic investigation

### Week 13: Security Standards and Policies
- Regulations, standards, frameworks, documentation, and personnel training

### Week 14: Risk Management and Privacy
- Privacy breaches, data classification, risk management, and business continuity
